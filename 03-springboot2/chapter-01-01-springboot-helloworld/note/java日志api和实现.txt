java 日志 api 和实现
1. 日志接口:slf4j(Simple Logging Facade for Java)
   - 日志实现:slf4j 的第一代实现 log4j，第二代实现:logback
2. log4j 和 log4j2 的关系:log4j2 是 apache 借用 log4j 之名开发的一个日志框架，与 log4j 并无直接关系
3. slf4j 和 log4j 的关系:最开始只有 slf4j，后来有了 log4j，但是 log4j 不能直接作为 slf4j 的实现，
   需要在中加一个 slf4j-log4j.jar 作为适配层
4. SpringBoot 选择 slf4j 接口和 logback 实现
5. 如何使用 slf4j:
   - Logger logger = LoggerFactory.getLogger(Xxx.class);
   - logger.info("hello world!");
6. 接口或者 jar 和具体的 jar 名称
   - slf4j:slf4j-api.jar
   - logback:logback-core.jar、logback-classic.jar
7. commons-logging:
   - commons-logging 也是一个日志接口，俗称 jcl，Spring 框架就使用的是 commons-logging 作为日志 api
