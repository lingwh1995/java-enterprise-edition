通过 @ConfigurationProperties 读取_@Configuration 将配置 bean 注入到容器中
1. 注意:
   - 如果不在 POJO 中使用 @Configuration，需要在主 Spring 应用程序主启动类中添加
     @EnableConfigurationProperties(LibraryBindWithoutBean.class) 以将属性绑定到 POJO 中
   - 如果在 POJO 中使用 @Configuration，不需要主 Spring 应用程序主启动类中添加
     @EnableConfigurationProperties(LibraryBindWithoutBean.class) 注解
