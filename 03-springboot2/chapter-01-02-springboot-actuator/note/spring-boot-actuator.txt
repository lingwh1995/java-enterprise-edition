spring-boot-actuator 查看 git 信息
1. 查看 git 相关信息(branch、commit)
   a. pom 增加 git-commit-id-plugin 插件
            <plugin>
                <groupId>pl.project13.maven</groupId>
                <artifactId>git-commit-id-plugin</artifactId>
                <version>2.1.15</version>
                <executions>
                    <execution>
                        <goals>
                            <goal>revision</goal>
                        </goals>
                    </execution>
                </executions>
                <configuration>
                    <dotGitDirectory>${project.basedir}/.git</dotGitDirectory>
                </configuration>
            </plugin>
   b. YML 中增加 git 相关配置
            management:
              info:
                git:
                  mode: full
   c. 生成 git.properties
      idea 右侧 maven 面板 -> spring-boot-actuator
      -> Plugins -> git-commit-id ->
      点击 git-commit-id:revision
   d. 启动项目
      访问:
      http://localhost:8080/actuator/info
      查看其中 git 相关信息(branch、commit)
   e. 特别注意:
      要先使用插件生成 git.properties 访问才能查看到 git 相关信息(branch、commit)，
      否则无法查看到 git 相关信息
