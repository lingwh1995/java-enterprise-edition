SpringBoot jar 包打成 war 包
1. 用途
   - 常用于前后端分离开发时合并前端和后端部署文件，最终将前后端部署文件打成一个 war 包，可以部署在 tomcat 容器中
2. 步骤
   a. 在 pom.xml artifactId 下配置 <packaging>war</packaging>
   b. 引入 maven 依赖
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-starter-tomcat</artifactId>
                <scope>provided</scope>
            </dependency>
   c. 在 pom.xml 中 build 节点添加如下配置
            <build>
                <plugins>
                    <plugin>
                        <groupId>org.springframework.boot</groupId>
                        <artifactId>spring-boot-maven-plugin</artifactId>
                    </plugin>
                </plugins>
            </build>
   d. 修改 Application.java
            @SpringBootApplication
            public class Application extends SpringBootServletInitializer {
                public static void main(String[] args) {
                    SpringApplication.run(Application.class, args);
                }

                @Override
                protected SpringApplicationBuilder configure(SpringApplicationBuilder application) {
                    return application.sources(Application.class);
                }
            }
   e. 将 war 包部署到 tomcat 后访问如下地址测试部署效果:
      http://localhost:8080/springboot-jar-package-to-war/package-to-war
